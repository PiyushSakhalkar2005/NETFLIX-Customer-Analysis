# Contributing to Netflix Data Engineering Pipeline

We welcome contributions from the community! To contribute:

1. **Fork the Repository**: Create a personal fork.
2. **Setup Environment**: Install dependencies using `pip install -r requirements.txt`.
3. **Write Tests**: Ensure any bug fixes or new features are accompanied by corresponding tests under `tests/`.
4. **Run Tests**: Execute `python -m pytest tests/` to confirm that all tests pass.
5. **Create a Pull Request**: Submit a clear description of the proposed changes.
